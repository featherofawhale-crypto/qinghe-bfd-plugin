# 清何剪辑工具箱 v2.0.1-beta.30（macOS / Windows）

beta.30 现已同时提供 macOS 和 Windows 安装包，两个平台继续使用独立的更新清单和安装包。

## 素材归纳修复

- 扫描阶段只依据“项目素材目录”判断文件是否误放在目录外。
- “归纳目录”只用于计算复制目标，不再作为允许素材来源的父目录。
- 修复归纳目录恰好包含现有素材时，扫描结果错误变成 0 的问题。
- 修改归纳目录会保留当前扫描列表、勾选状态和素材信息，可直接调整复制目标。
- 修改项目素材目录、时间线或扫描范围时，旧扫描结果仍会失效并要求重新扫描。

## macOS 字体收集修复

- 没有 `fc-list` 时直接扫描 `~/Library/Fonts`、`/Library/Fonts` 和 `/System/Library/Fonts`。
- 直接解析 TrueType、OpenType 及字体集合内部的家族、样式、全名和 PostScript 名称。
- `fc-list` 存在时合并两套结果，保留既有字体匹配能力。
- 达芬奇记录了字体名、但本机实际没有对应字体文件时，仍明确显示未匹配，不会伪造结果。
