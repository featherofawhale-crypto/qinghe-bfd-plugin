# 清何剪辑工具箱 v2.0.1-beta.29（macOS）

本次只发布新的 macOS 安装包。Windows 继续保留 v2.0.1-beta.28，旧版本 Release 和附件均不覆盖。

## 新增：误放素材归位补漏

此功能用于补查和归位已被工程使用、却误放在项目素材目录外的文件，不替代 DaVinci Resolve 自带的项目整理与媒体管理。

- 可按当前时间线 I/O、指定时间线或当前项目全部时间线扫描。
- 罗列不在所选项目素材目录内的已用素材，显示文件位置、大小、存在状态和使用位置。
- 扫描结果支持右键在 Finder 中显示；文件缺失时打开其上级目录。
- 可把外部素材复制到手动选择的归纳目录，并可选让 DaVinci Resolve 自动重新链接。
- 已移除“按项目名自动创建”选项，归纳前必须明确选择目标目录。
- 可选删除原文件，但只会在新副本哈希校验通过且 Resolve 重链接成功后执行；失败时保留原文件并报告原因。

## 新增：字体收集

- 扫描所选范围内所有可读取的 Text+ 文字层，以及 SRT 字幕轨使用的字体。
- SRT 字体从字幕轨设置读取，不依赖单条字幕片段的文字属性。
- 根据字体家族和字重定位本机实际字体文件，收集到手动选择的目录。
- 修复 DaVinci Resolve 图形界面环境 PATH 较短时找不到 Homebrew `fc-list` 的问题。
- 改进字体家族与字重匹配，降低 Bold、Light 等样式误收集。
- 无法由 Resolve API 读取字体属性的普通 Text 会明确列为未解析项，不会伪报已收集。

## 延续与修复

- 保留 beta28 的 Text+ 完整位置复制，包括变换、锚点、布局中心和着色位置等字段。
- 素材归纳使用临时文件、原子替换和 SHA256 校验；同名冲突会生成稳定的新名称。
- 本次没有增加 SRT 字体批量修改功能，SRT 仅支持字体检测与字体文件收集。
